KATALOG PT MAYA ANANDA LESTARI - VERSI FOTO ASLI

Isi:
- index.html = HTML/CSS katalog yang sudah dipasangkan dengan foto asli dari ZIP pengguna.
- assets/ = logo, 8 cover poster, dan foto galeri yang dikelompokkan per rumah.

Catatan:
- Struktur, teks, harga, tombol, dan gaya katalog berasal dari HTML katalog sebelumnya.
- Foto galeri dikelompokkan berdasarkan properti dari file yang diupload. Karena file asli tidak memiliki ID Canva per foto, urutan foto tidak diklaim sebagai pemetaan 1:1 terhadap asset Canva.
- Rumah 3 tidak memiliki foto galeri asli di ZIP; Rumah 4 hanya memiliki 4 foto galeri.
